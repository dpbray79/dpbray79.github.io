Dylan Bray • Product Design & System Architecture • 2025

Project Overview

English360 required a complete digital transformation to manage their growing language school operations. The challenge was to create an enterprise-grade learning management system that would work seamlessly across web and mobile platforms while integrating with existing Google Workspace infrastructure.

User Research & Personas

Primary User Types

👨‍🎓 Students

Primary Needs:

  • Easy lesson booking and rescheduling
  • Clear progress tracking with CEFR levels
  • Mobile access for on-the-go learning
  • Assignment submission and feedback
  • Transparent credit balance visibility

"I need to see my progress and book lessons while commuting"

👩‍🏫 Teachers

Primary Needs:

  • Complete student roster with notes
  • Schedule management and availability
  • Quick assignment grading interface
  • Progress reporting tools
  • Earnings transparency

"I need to manage 30+ students efficiently from my phone"

👨‍💼 Administrators

Primary Needs:

  • Real-time system overview
  • User management and permissions
  • Financial reporting and analytics
  • Schedule conflict resolution
  • Teacher performance monitoring
  • Student retention tracking
  • Capacity planning tools
  • Data export capabilities

"I need complete visibility across all locations and operations"

Key User Insights

Mobile Usage Patterns

60% of student interactions happen on mobile devices during commute times. Native app experience was critical for adoption.

Notification Preferences

Users wanted automated reminders 24 hours before lessons but were frustrated by excessive notifications.

User Journey Mapping

Student Journey
1

Discovery & Registration

Student visits English360.ca, browses instructors, completes online registration with language selection and CEFR level assessment.

2

Onboarding

Receives welcome email, downloads mobile app, completes profile setup, and schedules first lesson.

3

Active Learning

Attends lessons via calendar integration, submits assignments, receives feedback, tracks progress dashboard.

Teacher Journey
1

Morning Preparation

Reviews schedule, accesses student profiles, downloads lesson materials via mobile app.

2

Lesson Delivery

Conducts lesson, marks attendance in real-time, takes notes on student performance.

3

Post-Lesson Tasks

Submits lesson report, assigns homework, grades assignments, updates progress tracking.

Technical Architecture

Technology Stack

Platform Components

  • Power BI for analytics and reporting
  • Native iOS and Android app generation

System Capabilities

  • 99.9% uptime SLA

Weeks 4-6

Integration & Testing

Production deployment, staff training sessions, documentation, 30-day post-launch support
