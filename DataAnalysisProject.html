Halifax Housing Market & Big Data ETL 🛠️

A Data Science Project: Scaling Geospatial Analysis for High-Value Investment Insights

🚀 Project Challenge & Scope

This project was designed to solve a dual challenge: **1)** Demonstrate proficiency in processing large-scale geospatial data, and **2)** Generate actionable, micro-level property insights for a real estate client.

Core Technical Challenge: The 5GB+ Constraint

The central technical task involved extracting building footprints and calculating the precise **Area ($\mathbf{m^2}$) of every structure** from a multi-gigabyte OpenStreetMap (OSM) PBF file. This required a direct performance comparison between two leading technologies:

  • **PySpark/Sedona:** The distributed computing approach.
  • **Pandas/pyrosm/GeoPandas:** The single-node optimization approach.

Key Analytical Questions Addressed (7/10)

Using the derived $\mathbf{m^2}$ area, property assessment history, and granular permit data, the project answered 10 critical questions, including:

  1. **Undervalued Parcels (Q9):** Identifying properties that are statistically undervalued relative to nearby sales, normalized by $\mathbf{m^2}$ area. (The main project result).
  2. **Value per $\mathbf{m^2}$ (Q3):** Mapping the highest assessed value per unit of land/structure.
  3. **Redevelopment Candidates (Q5):** Finding parcels with low unit counts but large building footprints.
  4. **Permit Timeliness (Q6):** Calculating the average time from application to issuance for construction permits.

Technology Stack & Tools Used

The project leveraged a modern, mixed-stack approach combining scalable big data tools with efficient Python analysis libraries.

  • PySpark (Big Data)
  • Apache Sedona (Geospatial distributed processing)
  • Pandas/NumPy (Data Cleaning & Aggregation)
  • GeoPandas (Local Spatial Analysis)
  • pyrosm (OSM PBF local extraction)
  • Scikit-learn (Regression Modeling for Q9)
  • Matplotlib/Folium (Visualization)
  • Osmium-tool (PBF Clipping Utility)
