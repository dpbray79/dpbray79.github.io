## 🚀 Quick Start (Get Live in 2 Hours)

### Phase 1: Google Drive Setup (30 min)
1. Upload resume to Google Drive
2. Create portfolio PDF (combine your best work)
3. Upload portfolio PDF to Google Drive
4. Make all files "Anyone with the link"
5. Copy FILE_IDs from each link

### Phase 2: Update Files (20 min)
1. Open `index.html` in text editor
2. Find & Replace these placeholders:
   - `YOUR_RESUME_ID` → Your resume FILE_ID
   - `YOUR_GITHUB` → Your GitHub username
   - `YOUR_5S_ID` → 5S project FILE_ID
   - `YOUR_CLARITY_ID` → Clarity AI FILE_ID
   - `YOUR_ANALYTICS_ID` → Analytics FILE_ID
   - `YOUR_PORTFOLIO_ID` → Portfolio PDF FILE_ID
3. Save changes

### Phase 3: Deploy to GitHub (30 min)
1. Create GitHub account (if needed)
2. Create repository: `your-username.github.io`
3. Upload all files
4. Enable GitHub Pages in Settings
5. Wait 5 minutes for deployment

### Phase 4: Test & Share (10 min)
1. Visit `https://your-username.github.io`
2. Test all links
3. Check on mobile device
4. Share link in Detect application

**Your live portfolio URL:** `https://[your-github-username].github.io`
